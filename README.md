# 서울 문화행사 혼잡도 지도

서울의 문화행사를 고르고 방문을 준비하는 과정을  
**행사 탐색 → 시간 선택 → 주변 혼잡도 확인 → 행사 상세 확인 → 주변시설·이동 경로 확인**으로 연결한 지도 대시보드입니다.

문화행사 정보와 서울 주요 121개 권역의 혼잡도, 주변 카페·지하철 정보를 한 화면에서 확인할 수 있습니다.

> **행사가 어디서 열리는지 확인하는 데서 나아가, 주변 상황을 살펴보고 방문을 판단할 수 있도록 만드는 것을 목표로 했습니다.**

🌐 **[공개 지도 체험하기](https://hewa5318.github.io/seoul-culture-crowd-map/)**

> 현재 공개 버전은 **2026년 8월 27일에 수집한 기록을 조회하는 데모**입니다. 접속 시점의 실시간 혼잡도나 최신 행사 목록으로 자동 갱신되지 않습니다.

---

## 왜 만들었나요?

문화행사 정보를 찾아도 실제 방문을 결정하기 위해서는 추가로 확인할 것이 많습니다.

- 행사가 언제, 어디서 열리는지
- 주변이 얼마나 붐비는지
- 인파가 늘고 있는지, 줄고 있는지
- 가까운 지하철역이나 잠시 쉴 카페가 어디인지
- 행사장까지 어떻게 이동할지

각 정보를 따로 찾아보면 행사와 주변 상황을 연결해서 판단하기 어렵습니다.

그래서 다음 질문에서 시작했습니다.

> **“행사 위치와 시간대별 혼잡도, 주변 이동 정보를 하나의 지도에서 확인할 수 없을까?”**

---

## 어떻게 사용하나요?

### 1. 관심 있는 행사 찾기

지도에서 진행 중이거나 예정된 행사를 확인합니다. 행사 분류는 마커의 이모지로 구분할 수 있습니다.

진행 상태와 혼잡도 권역내·권역외 필터를 조합해 탐색할 대상을 좁힐 수 있습니다.

### 2. 확인할 시각 선택

혼잡도 기준시각을 선택하거나 **이전·다음** 버튼으로 이동합니다.

공개 버전에서는 2026년 8월 27일 **14:10~22:50 사이에 저장된 55개 관측 시각**을 선택할 수 있습니다. 선택한 시각에 맞춰 권역 색상과 행사 마커의 테두리 색상이 갱신됩니다.

시간 선택은 혼잡도 조회 기준을 바꾸며, 행사 목록과 진행·예정 상태는 저장된 행사 데이터 기준을 유지합니다.

### 3. 주변 혼잡도 확인

권역에 마우스를 올리거나 클릭하면 해당 시각의 혼잡정보를 확인할 수 있습니다.

혼잡도는 **여유·보통·약간 붐빔·붐빔**으로 구분합니다. 해당 시각의 관측 기록이 없거나 공식 권역 밖이면 **정보 없음**으로 표시합니다.

### 4. 행사 상세와 인파 변화 확인

행사 마커를 선택하면 팝업과 상세 패널이 열립니다.

행사명·포스터·기간·장소·연락처를 확인하고, 연결된 권역의 혼잡정보를 함께 볼 수 있습니다.

- 선택 시각의 혼잡등급과 추정인구
- 최근 인파 변화
- 해당 관측 기록에 포함된 다음 예측시각·예측 혼잡도·예측인구

혼잡등급 하나뿐 아니라 변화와 예측을 함께 살펴볼 수 있도록 구성했습니다.

### 5. 주변시설과 이동 경로 확인

저장된 주변 카페와 지하철 정보를 거리순으로 확인합니다. 카카오맵 길찾기와 행사 공식 홈페이지로 이동할 수도 있습니다.

지하철역은 **이동 거점**으로 안내하며, 공식 대피소로 표현하지 않았습니다.

---

## 이 프로젝트에서 중요하게 본 것

### 1. 위치가 가깝다는 이유만으로 혼잡도를 붙이지 않았습니다

문화행사 위치와 서울 주요 121개 권역의 경계를 공간조인해, 행사에 연결할 수 있는 공식 권역을 확인했습니다.

행사 좌표가 권역 밖에 있으면 가까운 권역의 혼잡도를 대신 보여주지 않았습니다. 방문자가 해당 행사장의 정보로 오해할 수 있기 때문입니다.

> **확인할 수 없는 정보는 ‘정보 없음’으로 남기는 것을 데이터 연결의 기준으로 삼았습니다.**

권역내·외 여부는 공간조인 결과인 `AREA_CD` 존재 여부로 판단합니다. 시간 선택 때문에 행사 자체의 위치 분류가 바뀌지 않도록 했습니다.

### 2. 권역 혼잡도와 행사장 혼잡도를 구분했습니다

행사에 연결한 혼잡도는 **행사가 위치한 권역의 추정치**입니다. 개별 행사장의 실제 입장객 수나 대기 인원을 직접 측정한 값은 아닙니다.

지도에서 행사 위치와 혼잡도를 함께 보여주되, 서로 다른 범위의 데이터를 같은 의미로 단정하지 않도록 했습니다.

### 3. 시간별 기록의 빈자리를 다른 시각의 값으로 채우지 않았습니다

관측 시각마다 기록이 있는 권역 수가 다릅니다.

선택 시각의 데이터가 없을 때 이전 값이나 다른 시각의 값을 가져오면, 사용자가 같은 시각의 정보로 받아들일 수 있습니다.

따라서 해당 시각의 기록만 사용하고, **데이터가 있는 권역 수와 정보가 없는 상태를 표시**했습니다.

### 4. 기능 구현 뒤 실제로 읽고 선택할 수 있는지 점검했습니다

지도를 만든 뒤에는 긴 행사명, 긴 주소, 같은 장소의 여러 행사처럼 실제 데이터에서 발생하는 문제를 보완했습니다.

| 발견한 문제 | 개선 내용 |
| --- | --- |
| 긴 행사명과 주소가 팝업 밖으로 넘침 | 반응형 폭과 줄바꿈 규칙 보완 |
| 주소의 두 번째 줄이 아이콘 아래로 내려감 | 아이콘과 본문을 분리해 텍스트 시작선 정렬 |
| 같은 장소의 행사 마커가 겹침 | 실제 좌표는 유지하고 화면상 마커를 분산 |
| 모바일에서 권역 정보를 확인하기 어려움 | 마우스 올리기 외에 클릭으로도 정보 확인 |
| 혼잡등급만으로 변화 방향을 알기 어려움 | 추정인구·최근 변화·다음 예측 정보 함께 표시 |

## 데이터를 어떻게 연결했나요?

데이터 연결 과정은 세 단계로 구성했습니다.

1. **행사와 권역 연결**: 행사 좌표가 121개 권역 중 어디에 포함되는지 확인하고 `AREA_CD`를 연결합니다.
2. **권역과 시간별 혼잡도 연결**: `AREA_CD`와 관측시각을 함께 사용해 선택한 시각의 기록을 조회합니다.
3. **행사와 주변시설 연결**: `EVENT_ID`를 기준으로 저장된 주변 카페·지하철 정보를 연결합니다.

```text
행사 좌표 + 121개 권역 경계
            ↓ 공간조인
      행사별 권역 코드
            ↓
선택 시각의 권역 혼잡도 연결
            ↓
행사 상세 + 주변시설 정보 연결
            ↓
   하나의 지도에서 탐색
```

Python·pandas·GeoPandas로 데이터를 전처리하고 공간조인했습니다. 지도는 HTML·CSS·JavaScript와 Kakao Maps JavaScript SDK로 구현하고, ChatGPT Sites로 공개 배포했습니다.

| 항목 | 공개 버전 기준 |
| --- | --- |
| 지도에 표시한 행사 | 진행 중·예정 400건 |
| 공식 혼잡도 권역과 연결된 행사 | 161건 |
| 공식 권역 밖의 행사 | 239건 |

행사와 혼잡도, 주변시설을 한 화면에서 탐색할 수 있는 공개 지도를 완성했습니다. 공개 사이트에서 지도·행사 마커·팝업 표시와 시간 변경에 따른 마커 색상·상세 정보 갱신을 확인했습니다.

이 수치는 구현 범위를 나타냅니다. 방문 판단에 미친 효과나 탐색 시간 단축은 별도의 사용자 테스트로 측정하지 않았습니다.

## 한계와 다음 단계

현재 지도는 저장된 기록을 조회하므로, 최신 정보를 제공하려면 수집·갱신 파이프라인을 추가해야 합니다.

또한 다음과 같은 한계가 있습니다.

- 공식 권역 밖의 행사와 관측이 누락된 시각은 혼잡정보를 제공하지 않습니다.
- 권역 혼잡도로 개별 행사장의 실제 혼잡도를 확정할 수 없습니다.
- 최근 30분 변화는 원천 데이터의 산출 기준과 실제 수집 간격을 함께 확인해야 합니다.
- 예측은 원천 기록에 포함된 값이며, 이 지도에서 별도 예측 모델을 실행하지 않습니다.
- 주변시설 정보도 저장된 조회 결과로, 현재 영업·운행 상태를 보장하지 않습니다.

다음 단계에서는 여러 날짜의 관측을 누적하고, 날짜별 비교와 갱신 상태 표시를 확장할 수 있습니다. 사용자 테스트를 통해 필터와 상세 패널이 실제 탐색에 도움이 되는지도 확인할 필요가 있습니다.

## 직접 실행하려면

공개 지도는 설치 없이 사용할 수 있습니다. 로컬에서 확인하려면 Python이 설치된 환경에서 다음 명령을 실행합니다.

```bash
git clone https://github.com/hewa5318/seoul-culture-crowd-map.git
cd seoul-culture-crowd-map
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 별도 패키지 설치나 빌드는 필요하지 않으며, 지도 표시에는 인터넷 연결이 필요합니다.

다른 환경에서 실행할 때는 [카카오디벨로퍼스](https://developers.kakao.com)의 JavaScript 키와 **JS SDK 도메인** 설정을 확인합니다. 자신의 카카오 앱으로 실행하려면 `index.html`의 기존 SDK 로딩 태그에서 `appkey`를 교체합니다.

```html
<script src="https://dapi.kakao.com/v2/maps/sdk.js?appkey=YOUR_JAVASCRIPT_KEY&autoload=false"></script>
```

로컬 실행 주소 `http://localhost:8000` 또는 실제 배포 주소를 해당 키의 허용 도메인으로 등록합니다. 브라우저용 JavaScript 키의 허용 도메인을 관리하고, 서버용 REST API 키·Admin 키는 공개 저장소에 포함하지 않습니다.

### 저장소 구성

```text
seoul-culture-crowd-map/
├── index.html      # 지도 화면, 동작 코드, 표시용 데이터
├── README.md       # 프로젝트 설명과 실행 안내
└── .gitattributes  # Git 파일 처리 설정
```

이 저장소는 데이터가 포함된 완성본 HTML을 제공합니다. 데이터 전처리 노트북과 원천 Excel 파일은 현재 저장소에 포함되어 있지 않습니다.
